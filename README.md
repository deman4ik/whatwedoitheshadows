# Вечность. С соседями.

30 коротких историй о создании «Реальных упырей»: читательский сайт по материалам презентации, без сюжетных развязок.

**Сайт:** https://deman4ik.github.io/whatwedoitheshadows/

Статический HTML, CSS и JavaScript. Все истории присутствуют в HTML и доступны без JavaScript; скрипт добавляет поиск и подсветку текущей главы. Изображения и шрифты хранятся локально, внешних аналитических сервисов нет.

## Правка материалов

1. Измените тексты, изображения или ссылки в `content/stories.json`.
2. Выполните `python3 scripts/build.py`, чтобы обновить `index.html`.
3. Закоммитьте изменения в ветку `master`: GitHub Pages публикует корень этой ветки.

Для локального просмотра: `python3 -m http.server 8769`, затем откройте `http://localhost:8769/`.

`scripts/prepare-content.py` импортирует исходные материалы из соседней папки проекта презентации. Для редактирования уже подготовленного сайта повторный импорт не нужен.

Шрифты Oswald и Noto Sans распространяются под SIL Open Font License; лицензии находятся в `assets/fonts/`. Кадры, афиши и фотографии используются как иллюстрации к материалу о фильме; сведения об исходных изображениях — в `assets/ASSETS.md`, источники фактов — у каждой истории.
